# 名词解释

看代码或看日志时遇到这些词，先回来查一下。

| 名词 | 是什么 | 在本项目里的位置 |
|---|---|---|
| **HDC** | HarmonyOS Device Connector，鸿蒙的设备调试工具链，作用类似 Android 的 `adb` | 编译、安装、`hdc shell` 都用它 |
| **`hdc shell`** | 通过 HDC 在设备上执行一条命令，执行身份是设备上的 `shell` 用户（`uid=2000`） | 本项目的全部能力最终都落到这里 |
| **uid=2000(shell)** | 鸿蒙里的一个系统用户，权限比普通 App（uid 随机且沙箱化）大很多，但**远小于 root** | 「概览」页的「执行身份」、诊断页结论 |
| **hdcd** | 设备侧的 HDC 守护进程，监听本机回环端口，接受握手后替调用方执行 shell | `LocalHdc.ets` 直接与它通信（免电脑方案） |
| **broker** | 电脑上跑的一个小程序，收到 App 的 HTTP 请求后替你调 `hdc shell` | `pc-broker/broker.js`（有电脑时的备选方案） |
| **rport / fport** | HDC 的端口映射：`rport` 把设备侧端口反向映射到电脑，`fport` 把电脑侧端口转发到设备 | broker 方案靠 `rport` 让 App 访问电脑 |
| **HAP** | HarmonyOS Ability Package，鸿蒙的安装包格式，相当于 Android 的 APK | `release/*.hap` |
| **Stage 模型** | 鸿蒙当前的应用架构模型（有 UIAbility、WindowStage 等概念），区别于早期的 FA 模型 | `entry/src/main/ets/entryability/` |
| **ArkTS** | 鸿蒙的主力开发语言，TypeScript 的严格版（禁 `any`、禁动态属性） | `entry/**/*.ets` |
| **ArkUI** | 鸿蒙的声明式 UI 框架，写法类似 SwiftUI / Flutter | `pages/Index.ets` 里的 `@Builder`、`Column()` 等 |
| **@Builder** | ArkUI 里复用一段 UI 的写法（类似「组件片段」），本项目六个功能页都是 `@Builder` | `Index.ets` 中 `ScreenTab()` 等 |
| **@State** | ArkUI 的状态变量，改了它界面会自动刷新 | `Index.ets` 顶部的 `curTab` / `funcSel` 等 |
| **`SaveButton`** | 系统提供的「保存到相册」安全控件，用户点击即临时授权，不需要申请受限权限 | 屏幕页保存截图用的就是它 |
| **profile（`.p7b`）** | 签名配套的授权文件，里面写明包名、证书、允许调试的设备 UDID | 由 DevEco 自动签名生成，**不要外传** |
| **UDID** | 设备的唯一标识，调试 profile 靠它限定「只能在哪些设备上装」 | 设备上 `hdc shell bm get -u` 可查 |
| **preferences** | 鸿蒙的轻量键值存储（类似 SharedPreferences） | 本应用存令牌、PIN、主题、hdcd 端口与密钥 |
| **DFX** | Design for X，指可维护性/可诊断性相关能力（日志、崩溃、性能采集） | 「诊断」页与该项目的崩溃排查 |
| **ffsz()** | 本工程自定义的函数，把「字号档位」换算成实际字号（用户可在外观设置里调大小） | `Index.ets` 顶部 |

## 容易混淆的三个「权限」

1. **系统权限（permission）**：写在 `module.json5` 的 `requestPermissions`，要用户同意。本项目只有 `INTERNET`。
2. **DAC 权限**：Linux 传统权限，由「你是谁（uid）」决定能读哪些文件。`shell` 读别的 App 私有目录会被
   `Permission denied` 拒绝——这是**正常的**，不是漏洞。
3. **签名授权**：设备只安装签名与 profile 匹配的包，跟上面两者无关。

## 常见返回值

| 输出 | 含义 |
|---|---|
| `EACCES` / `Permission denied` | 当前 uid 没权限读，属于正常的权限隔离 |
| `ENOENT` / `No such file` | 路径不存在（也可能因为挂载命名空间看不到） |
| `exit 0` | 命令执行成功 |
| `exit 1`、`exit 127` | 失败 / 命令不存在 |
