# 快速开始（零基础版）

> 这份文档假设你**从没写过鸿蒙应用**，也没用过 `hdc`。
> 按顺序做完 8 步，就能在自己设备上跑起来。每步都写了「成功时你会看到什么」。

---

## 第 0 步：先搞清楚要装哪些东西

| 要装的东西 | 作用 | 从哪来 |
|---|---|---|
| **DevEco Studio** | 华为官方的鸿蒙开发工具，自带 SDK / 编译器 / 签名工具 / `hdc` | 华为开发者官网「DevEco Studio」下载页 |
| **HarmonyOS SDK** | 编译工程需要，DevEco 安装时会一起装 | 随 DevEco 安装 |
| 一台鸿蒙设备 | 真机运行 | 手机 / 平板，需 API 12 及以上 |

> 只用模拟器也能编译运行，但本项目的核心能力是**调用设备上的 hdcd**，模拟器上没有真实 `hdcd`，
> 因此「连接状态」会一直显示未连接。**要验证功能必须用真机。**

---

## 第 1 步：安装 DevEco Studio

1. 下载安装包，一路下一步，路径**不要带中文和空格**（例如 `D:\DevEco`）。
2. 首次启动会让你选 SDK 目录，保持默认即可，等它下载完。
3. 装完在开始菜单里能找到 **DevEco Studio**。

**成功标志**：能打开 DevEco Studio，欢迎页正常显示。

---

## 第 2 步：确认 `hdc` 在哪

`hdc` 是鸿蒙的设备调试命令行工具，相当于 Android 的 `adb`。它随 DevEco 一起装好，位置一般是：

```
<DevEco 安装目录>\sdk\default\openharmony\toolchains\hdc.exe
```

打开 PowerShell，先临时把它加进 PATH（只对当前窗口有效）：

```powershell
$hdc = "D:\DevEco\sdk\default\openharmony\toolchains\hdc.exe"
& $hdc version
```

**成功标志**：打印出版本号（形如 `Ver: 3.x.x`）。

> 想长期可用，把 `...\toolchains` 加进系统环境变量 PATH 即可。

---

## 第 3 步：设备打开开发者模式与 USB 调试

在**设备上**操作：

1. 设置 → 关于本机 → 连续点击「软件版本」7 次左右，提示「已进入开发者模式」；
2. 设置 → 系统 → 开发者选项 → 打开 **USB 调试**；
3. 用数据线连接电脑（**要能传数据的线**，纯充电线不行）；
4. 设备上会弹「允许 USB 调试吗」，勾选「始终允许」并确定。

然后在电脑上：

```powershell
& $hdc list targets
```

**成功标志**：输出一行设备序列号（例如 `74CUN25C18G03463`）。
如果输出 `[Empty]`，看本文「常见问题」第 1 条。

---

## 第 4 步：用 DevEco 打开工程

1. DevEco 欢迎页 → **Open** → 选择本项目根目录（就是含 `AppScope`、`entry`、`build-profile.json5` 的那一层）；
2. 首次打开会提示同步 / 下载依赖，点 **Sync Now**，等进度条走完（几分钟，取决于网速）；
3. 如果提示 `ohpm install` 失败，检查网络或代理后重试。

**成功标志**：左侧工程树能看到 `entry/src/main/ets/pages/Index.ets`，下方没有大片红色报错。

---

## 第 5 步：生成签名（必须做，否则装不上）

鸿蒙设备只安装**已签名**的包。最简单的办法是用 DevEco 的自动签名：

1. DevEco 右上角登录**华为账号**（没账号就注册一个，免费）；
2. 菜单 **File → Project Structure → Signing Configs**；
3. 勾选 **Automatically generate signature**（自动生成签名）；
4. 点 **Apply / OK**，等它生成证书和 profile。

**成功标志**：工程根目录的 `build-profile.json5` 里出现了 `signingConfigs` 段，
且 `entry/build/default/outputs/default/` 下能产出**带签名**的 hap（文件名不含 `unsigned`）。

> 自动签名会自动把你的设备 UDID 写进 profile。**换设备要重新生成一次**，否则新设备装不上。

---

## 第 6 步：编译

方式 A（在 DevEco 里）：菜单 **Build → Build Hap(s)/APP(s) → Build Hap(s)**。

方式 B（命令行，推荐出正式包时用）：

```powershell
# 先告诉脚本 DevEco 装在哪
$env:DEVECO_HOME = "D:\DevEco"
.\build.ps1            # debug 包
.\build.ps1 -Release   # release 包（体积更小）
```

**成功标志**：最后一行是 `构建成功 -> ...entry-default-unsigned.hap`。
（命令行构建不带签名，得到的是 unsigned 包，下一步用 DevEco 运行或自行签名。）

---

## 第 7 步：安装到设备

**最省事的方式**：在 DevEco 里点绿色三角 ▶ Run，它会自动签名、安装、启动。

**用命令行**（需要已签名的 hap）：

```powershell
& $hdc install -r "路径\到\已签名.hap"
```

**成功标志**：输出 `install bundle successfully`，设备桌面上出现「星枢」图标。

---

## 第 8 步：第一次打开要做什么

1. 打开 App，顶部胶囊显示 **未连接** 时，在「概览」页点一下 **启动（已连接，点此重连）**；
2. 稍等几秒，顶部变成 **已连接 本机 · <你的机型>**，说明 App 已经和设备的 `hdcd` 握手成功；
3. 到「功能」页，左侧侧栏点「屏幕」→ 点「截取当前屏幕」，能看到自己屏幕的截图，说明整条链路通了；
4. 想用 HTTP 接口，去「接口」页打开网关开关，复制令牌，按 `docs/接口调用.md` 里的 curl 试一次 `/v1/ping`。

**成功标志**：截图能出来、`/v1/ping` 返回 `{"ok":true,...}`。
