# 更新说明：1.2.0 → 1.2.1

**发布日期**：2026-11-22
**版本号**：1.2.0（1002000）→ **1.2.1（1002001）**
**安装包**：约 625 KB（release，未签名）

---

## 一句话总结

界面从「九个平铺页签」改成「四个主页面 + 功能侧栏」，新增了终端页，并把权限最大的
`/v1/shell` 端点默认关掉；同时修掉了几处版本号、参数拼接和网关健壮性问题。

---

## 一、界面变化（最直观的部分）

### 底栏

| | 1.2.0 | 1.2.1 |
|---|---|---|
| 页签数量 | 9 个：概览 / 屏幕 / 进程 / 文件 / 应用 / 解锁 / 诊断 / 接口 / 关于 | **4 个：概览 / 功能 / 接口 / 关于** |
| 屏幕、进程、文件、应用、解锁、诊断 | 各自一个底栏页签 | 全部并入「功能」页，左侧侧栏切换 |
| 手机上的占用 | 九项挤在一行，字号被压 | 四项，间距充足 |

### 功能页

- 左侧新增 132vp 竖排侧栏（平板）；手机自动收窄到 92vp，超窄 80vp，横竖屏切换与分屏会重算；
- 侧栏选中项：金黄文字 + 深金底色 + 左侧 3vp 强调条；
- 侧栏自身可滚动，系统字号调大也不会顶出屏幕。

### 概览页

- 设备信息下方新增两行共六张「快捷功能」卡片（屏幕 / 进程 / 文件 / 应用 / 解锁 / 诊断），
  点一下直接跳到对应子页，不用先点底栏再找侧栏。

> 六个子页的**内容、按钮、交互完全没变**，只是入口从底栏搬到了侧栏。

---

## 二、新增功能

### 1. 终端子页（功能侧栏第 7 项）

- 输入任意 shell 命令，输出累积显示，等宽字体、可长按复制；
- **cwd 由页面维持**：纯 `cd xxx` 会用 `cd xxx && pwd` 回读真实路径，其它命令自动前缀当前目录，
  看起来像连续会话（底层 hdc 是非交互 exec，本身不留状态）；
- 历史 50 条（界面显示 8 条，点一下回填），`clear` 清屏；
- 输出上限 200 KB、单条命令 30 秒超时；
- 状态行显示 `exit 0 / 非 0` 与当前 cwd。

### 2. `/v1/shell` 开关（接口页「高危端点」）

- 1.2.0：只要网关开着，任何拿到令牌的本机应用都能执行任意 shell 命令；
- 1.2.1：**默认关闭**。关着时端点直接返回错误，`/v1/capabilities` 也不再列出 `shell`；
- 打开后每次调用写一条审计日志（时间 + 命令前 120 字符）；
- App 内「终端」页不受此开关影响（本地能力，不走 HTTP）。

## 三、修复与加固

| # | 1.2.0 的问题 | 1.2.1 的处理 |
|---|---|---|
| 1 | 界面与「关于」页硬编码 `v1.2.0 · build 1002000`，与包信息不一致 | 改为 `bundleManager` 运行时读取，三处统一 |
| 2 | `/v1/ping` 返回写死 `"version":"1.2.0"` | 同上，运行时读取 |
| 3 | shell 参数用双引号拼接（`cat "…"`、`bm install -p "…"` 等 8 处），路径含 `"`/`$` 会把命令拼歪 | 统一单引号转义 `Gateway.q()` |
| 4 | 网关 `Content-Length` 未校验，`parseInt` 返回 NaN 时静默按 0 处理、body 被截 | 校验 NaN 与负数 |
| 5 | 网关无请求体上限，本机客户端可灌大包吃内存 | 3 MB 上限（413）、header 64 KB 断连 |
| 6 | 半截请求 / 空连接长期占用句柄 | 每连接 15 秒兜底关闭 |
| 7 | 声明了未使用的 `GET_NETWORK_INFO` | 已移除，权限清单只剩 `INTERNET` |

## 四、行为变化（升级前务必看）

1. **`/v1/shell` 默认不可用**。如果你的其它应用依赖它，升级后要先去「接口」页手动打开开关，
   否则会收到 `shell 端点未开启` 的错误。
2. **底栏少了 5 个入口**，但功能都在「功能」页的侧栏里；概览页的快捷卡片也能直达。
3. **权限清单少了一条** `GET_NETWORK_INFO`。若你有代码检查权限列表，注意这一项不再存在。
4. **版本号变了**：1002000 → 1002001，可以覆盖安装 1.2.0。

## 六、升级与回滚

**升级**

```powershell
& $hdc install -r "release\StarPivot-v1.2.1-r4-unsigned.hap"   # 需先签名
```

- 覆盖安装**保留**应用数据（令牌、hdcd 配对密钥、主题设置）；PIN 也在，无需重填。
- 如果设备上装过 versionCode 更高的内部测试版（1002002+），会被系统拒绝覆盖：先卸载或把
  versionCode 调到更高再签名。

**回滚**

装回 1.2.0 的包即可；但注意 versionCode 变小，系统会拒绝「降级覆盖」，需要先卸载当前版本
（卸载会清掉令牌与 PIN）。

## 七、兼容性

- `minAPIVersion` 未变（API 12+），1.2.0 能装的设备 1.2.1 也能装；

- 已在 MatePad 11.5 S（OpenHarmony 7.0.0.111 / API 26）实机验证；其它机型未验证。
