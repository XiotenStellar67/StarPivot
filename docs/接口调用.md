# 接口调用示例

本项目的接口都在**本机回环**上，其它应用（或在设备上用 `curl`）直接访问 `127.0.0.1:18790` 即可，
不需要连电脑。端口可在「接口」页改。

---

## 一、三条铁律

1. **只有 `/v1/ping` 不需要令牌**，其它全部要带请求头 `X-StarPivot-Token`；
2. 请求体是 JSON（`Content-Type: application/json`），方法用 `POST`；
3. 网关开关在「接口」页，关着的时候连不上，先打开。

令牌在「接口」页，「复制」按钮可一键拷到剪切板。

---

## 二、先验证通路

```bash
curl -X POST http://127.0.0.1:18790/v1/ping
```

返回：

```json
{"ok":true,"service":"starpivot","version":"1.2.1","port":18790,"broker":true}
```

`broker` 为 `true` 表示 shell 通道可用。这一步不需要令牌；如果它都不通，先回去查「未连接」问题。

---

## 三、带令牌的请求

```bash
TOKEN="你在接口页看到的令牌"

curl -X POST http://127.0.0.1:18790/v1/process/list \
  -H "X-StarPivot-Token: $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{}'
```

返回结构统一是 `{"ok":true,...}` 或 `{"ok":false,"error":"..."}`，`401` 表示令牌不对。

## 四、常用端点与参数

### 设备

| 端点 | 请求体 | 说明 |
|---|---|---|
| `/v1/device` | `{}` | 机型、品牌、API 版本、系统版本 |
| `/v1/device/params` | `{}` | 系统参数 |
| `/v1/device/storage` | `{}` | `/data` 空间 |
| `/v1/device/udid` | `{}` | 设备 UDID |
| `/v1/device/memory` | `{}` | 全进程内存明细（`hidumper --mem`） |
| `/v1/device/cpu` | `{}` | CPU 占用 |
| `/v1/device/cpufreq` | `{}` | 每核频率 |
| `/v1/device/top` | `{}` | `top -n 1` 快照 |

### 屏幕

| 端点 | 请求体 |
|---|---|
| `/v1/screen/capture` | `{"width":1600,"height":0}`（0 = 按屏幕比例；都不传默认 1600 宽） |
| `/v1/screen/tap` | `{"x":400,"y":1200}` |
| `/v1/screen/swipe` | `{"x1":400,"y1":1500,"x2":400,"y2":600,"duration":300}` |
| `/v1/screen/key` | `{"key":"Back"}` |
| `/v1/screen/text` | `{"text":"hello"}` |
| `/v1/ui/dump` | `{}`（返回界面层级 JSON 字符串） |

`/v1/screen/capture` 返回 `{"ok":true,"mime":"image/jpeg","base64":"..."}`，需要自己 base64 解码成图片。

### 进程 / 文件 / 应用

| 端点 | 请求体 | 注意 |
|---|---|---|
| `/v1/process/list` | `{}` | 返回结构化列表 |
| `/v1/process/detail` | `{"pid":1234}` | |
| `/v1/process/kill` | `{"pid":1234}` | 只能杀自己权限内的进程 |
| `/v1/file/list` | `{"path":"/data/local/tmp"}` | |
| `/v1/file/read` | `{"path":"/data/local/tmp/a.txt"}` | 大文件会被超时/截断 |
| `/v1/file/write` | `{"path":"...","content":"..."}` | 覆盖写 |
| `/v1/file/remove` | `{"path":"..."}` | 删除 |
| `/v1/app/list` | `{}` | 可能较大 |
| `/v1/app/detail` | `{"bundle":"com.xxx"}` | |
| `/v1/app/start` | `{"bundle":"com.xxx"}` | 会自动查主 Ability |
| `/v1/app/stop` | `{"bundle":"com.xxx"}` | |
| `/v1/app/install` | `{"path":"/data/local/tmp/x.hap","replace":true}` | 路径是**设备上**的已签名 hap |
| `/v1/app/uninstall` | `{"bundle":"com.xxx"}` | |
| `/v1/app/clean` | `{"bundle":"com.xxx","mode":"cache"}` | `mode=data` 才清数据 |
| `/v1/app/shared` | `{}` | 共享库清单 |
| `/v1/app/patch` | `{"bundle":"com.xxx"}` | quickfix 状态 |

### 日志 / 网络

| 端点 | 请求体 |
|---|---|
| `/v1/log/events` | `{"type":"","domain":"","name":"","count":20}` |
| `/v1/log/hilog` | `{"count":200}` |
| `/v1/log/crash` | `{}` |
| `/v1/log/crashDetail` | `{"id":"..."}` |
| `/v1/net/sockets` | `{}` |
| `/v1/net/iface` | `{}` |
| `/v1/net/traffic` | `{}` |
| `/v1/net/http` | `{"url":"https://example.com"}`（只支持 HTTPS，走设备侧 openssl） |

### 解锁 / shell

| 端点 | 请求体 | 注意 |
|---|---|---|
| `/v1/screen/wake` | `{}` | 亮屏 |
| `/v1/screen/unlock` | `{"delay":800,"gap":300,"off":false}` | **PIN 不接受传入**，只读本机保存的 |
| `/v1/shell` | `{"cmd":"ls /data/local/tmp"}` | **默认关闭**，需在「接口」页打开「高危端点」 |

## 五、在 ArkTS 应用里调用

```ts
import { http } from '@kit.NetworkKit';
import { BusinessError } from '@kit.BasicServicesKit';

async function callPivot(path: string, body: string): Promise<string> {
  const req = http.createHttp();
  try {
    const res = await req.request('http://127.0.0.1:18790' + path, {
      method: http.RequestMethod.POST,
      header: {
        'Content-Type': 'application/json',
        // 换成你自己的令牌
        'X-StarPivot-Token': 'YOUR_TOKEN_HERE'
      },
      extraData: body,
      connectTimeout: 5000,
      readTimeout: 30000
    });
    return res.result as string;
  } finally {
    req.destroy();
  }
}

// 用法
callPivot('/v1/process/list', '{}').then((s: string) => {
  console.info(s);
});
```

注意事项：

- 你的应用需要声明 `ohos.permission.INTERNET`；
- 令牌**不要硬编码进要发布的代码**，放到自己的配置里，或者让用户手填；
- 返回体是字符串，记得 `JSON.parse` 后再用；
- 截屏返回的 base64 很大，注意内存，别一次存多张。

## 六、Python 调用的最小例子

```python
import requests

BASE = "http://127.0.0.1:18790"
H = {"X-StarPivot-Token": "<令牌>", "Content-Type": "application/json"}

print(requests.post(f"{BASE}/v1/ping").json())
print(requests.post(f"{BASE}/v1/device", headers=H, json={}).json())
```

> 从电脑上调设备上的回环端口，需要先做端口映射：
> `hdc fport tcp:18790 tcp:18790`，然后把 `127.0.0.1` 换成映射后的地址。
